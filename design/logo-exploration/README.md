# Second logo exploration

Preserves the first round in ../logo-alternatives and adds four variants of the selected fan-and-point concept plus three distinct alternatives. Application assets are unchanged.

## Fan variants

- V1 balanced: five evenly spaced rays around a separated circular hub. Recommended for its local reference and quieter proportions.
- V2 three rays: strongest reduction, with less specific Karlsruhe recognition.
- V3 solid: broad filled spokes for a bolder silhouette.
- V4 technical: flat line endings using the same geometry as V1.

## New directions

- A1 interrupted road: a road interrupted by a construction bar; direct roadwork reference but less local identity.
- A2 fan bucket: an excavator bucket containing fan-shaped cutouts; closest connection to the product name.
- A3 road monogram: an F-shaped street junction with a yellow starting point; more typographic and abstract.

Each concept has a 64-unit SVG mark, a 512-unit app-icon SVG, and a 192 px PNG preview. Comparison sheets include wordmarks and icons at 48, 32, and 16 px, monochrome marks, and dark backgrounds. Preview wordmarks use system sans-serif fonts. All standalone marks have transparent backgrounds; the bucket uses a vector mask for its cutouts.
