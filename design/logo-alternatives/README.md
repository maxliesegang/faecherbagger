# Logo alternatives

Four minimal vector concepts using the application's existing navy (#454b6b) and construction yellow (#f4a300).

Open comparison.png for the overview. Each numbered concept includes a transparent SVG mark, an app-icon SVG with a navy background, and a 192 px PNG preview. The comparison shows a wordmark, small app icons, a monochrome mark, and a dark-background lockup.

1. Fan and point (recommended): Karlsruhe's radial street layout with a construction marker.
2. Fan excavator: a compact excavator with a fan-shaped bucket.
3. Road fan: converging streets with a construction accent.
4. Fan pin: a map marker containing a fan.

These are design alternatives; the application's current icons have not been replaced. Preview wordmarks use a system sans-serif font. SVG symbols contain no fonts or external dependencies.
